# اکسیر · Aksir (نسخهٔ کاملاً آفلاین)
طراحی و توسعه: سروش شجاعی · Soroush Shojaei

اپ شناسایی دارو از روی عکس بسته. موتور OCR (Tesseract فارسی+انگلیسی)، پایگاه دارو و منطق پاسخ‌گویی همه داخل خود اپ هستند؛ بعد از نصب هیچ اینترنتی لازم نیست.

## ۱) نصب به‌صورت PWA (ساده‌ترین راه)
پوشهٔ `www` را روی یک هاست HTTPS رایگان بگذار (GitHub Pages / Cloudflare Pages / Netlify). یک بار با Chrome گوشی بازش کن (~۱۲ مگابایت دانلود می‌شود) → منو ← «Install app / افزودن به صفحهٔ اصلی». از آن به بعد کاملاً آفلاین کار می‌کند.
> برای تست روی کامپیوتر: `cd www && python -m http.server 8000` و باز کردن `http://localhost:8000`.

## ۲) ساخت APK (بدون نصب Android Studio)
1. این پوشه را در یک مخزن GitHub بگذار (Push).
2. تب Actions ← «Build Android APK» ← Run workflow.
3. بعد از چند دقیقه فایل `aksir-apk` (حاوی app-debug.apk) را از Artifacts دانلود و روی گوشی نصب کن (اجازهٔ نصب از منبع ناشناس).
برای انتشار در بازار/پلی‌استور باید APK/AAB امضاشده بسازی (Android Studio یا Gradle signing).

## افزودن/ویرایش دارو
- `www/data/aliases.js`: نام‌های شناخته‌شده (برای تطبیق OCR).
- `www/data/drugs.js`: کارت اطلاعات هر دارو با `d(key, فارسی, دسته, {use,how,side,serious,inter,warn,contra,preg,over})`؛ مورد‌ها با `|` جدا می‌شوند.
- بعد از تغییر، نسخهٔ `V` را در `www/sw.js` عوض کن تا کش به‌روز شود.

## هشدارهای مهم
- محتوای ۵۳ داروی فعلی را من نوشته‌ام (اطلاعات عمومی، بدون دوز). **قبل از انتشار عمومی حتماً داروساز/پزشک آن را بازبینی کند.**
- OCR فارسی روی بستهٔ براق یا فونت تزئینی ممکن است اشتباه کند؛ همیشه نام را با بسته تطبیق بده (جست‌وجوی دستی هست).
- صدای فارسی به بستهٔ صوتی فارسی Google TTS روی گوشی نیاز دارد (تنظیمات ← خروجی تبدیل متن به گفتار).
- محتوای دارو فعلاً فقط فارسی است (رابط انگلیسی هم دارد).
